# DashbordGit v0.5.2 — Chromium, lecture DOM et consentement API

**Publication GitHub en préversion (test Android)** — 11 octobre 2026.

## Nouveautés
- Mosaïque Android WebView (Chromium système) : navigation vers les pages GitHub Actions/commits/runs, zoom, rafraîchissement manuel par carte et ouverture externe.
- Mini-explorateur visible sur la page d'accueil, parcourant séquentiellement les pages publiques des projets sélectionnés. Aucun polling propre au Dashboard ; les pages GitHub peuvent effectuer leurs propres requêtes.
- Statuts de build déduits uniquement des noms accessibles `aria-label` reliés à l'URL et à l'identifiant exact du run : réussi / en cours / échoué ; inconnu reste gris.
- Cartes mises à jour progressivement, sans effacer la liste défilante pendant la lecture.
- Vérification REST supplémentaire **facultative**, avec boutons visibles **CONTINUER SANS API** et **AUTORISER CETTE VÉRIFICATION**, et mémorisation désactivée par défaut.
- Supertonic 3 INT8 français : voix 1, seed 2026 ; choix de voix/seed/morcellement dans les paramètres. Sauvegardes et journal conservés.

## Vérifications
- CI Android (tests Kotlin et compilation) validée sur la branche de travail au build #84 ; une nouvelle compilation et les mêmes tests doivent réussir sur `main` pour publier cette préversion.
- Vraies pages GitHub testées en Chromium en CI contre les statuts officiels : `completed successfully`, `currently running`, `failed`.
- Journal Android utilisateur (11/10/2026 14:29–14:35) : trois dépôts explorés ; succès reliés aux vrais identifiants SpaceFortressVs, MassAI et DashbordGit ; aucune erreur WebView rapportée ; Supertonic 3 vocalise correctement.

## Limites connues
- La fluidité du **défilement des cartes** et les gestes tactiles de la mosaïque restent à valider/ajuster sur le téléphone ; ne pas considérer ces points clos.
- Le changement spontané d'un build « en cours » à « terminé » sans rechargement n'a pas été confirmé sur toute la durée d'un vrai workflow Android.
- Les captures figées de mosaïque ne sont pas des statuts en direct ; le HTML public de GitHub peut changer et rendre un état inconnu.
- Le fichier joint est un **APK de test signé en mode debug**, pour ARM64 ; ce n'est ni un AAB signé pour Google Play, ni une mise à jour garantie de toutes les installations précédentes. Une clé de signature de test différente peut empêcher l'installation par-dessus l'ancienne application.
