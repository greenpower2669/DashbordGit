# DashbordGit v0.6.0 — sonothèque Djipie évolutive

Publication GitHub de l'APK Android ARM64 avec explorateur de sons Djipie. La compilation est de type **debug** : ce n'est pas un AAB signé pour Google Play ni une distribution à signature pérenne.

## Nouveautés
- 🎧 Explorateur de la bibliothèque sonore privée Djipie : familles, recherche, écoute, export individuel et compteur de sons.
- 🔄 **Catalogue stable sur la branche `main` de Djipie**. Lorsqu'un nouveau son est publié/indexé puis fusionné dans le catalogue central, il apparaît au prochain appui sur **Charger le catalogue**, sans modification de l'APK.
- Catalogue Djipie initial : **579 références**, dont la guitare électrique `Musique_electrique_guitare_jingle_001.wav` et 25 nouveaux effets OGG. Les nombres évolueront sans mise à jour de l'application.
- 🔐 Jeton GitHub limité au seul dépôt privé `Djipie` (`Contents: Read-only`), mémorisé chiffré dans Android Keystore, jamais embarqué dans l'APK.
- Téléchargement individuel à la demande, vérification de taille et SHA-256, redécouverte des identifiants de fichiers après republication des Releases.
- Tableau de bord original, navigateur Chromium et voix Supertonic 3 préservés.

## Utilisation
1. Installer l'APK `DashbordGit-v0.6.0-debug.apk`.
2. Ouvrir **🎧 EXPLORATEUR DE SONS DJIPIE**, puis **🔐 Connexion** et enregistrer un jeton d'accès au dépôt privé.
3. Appuyer sur **🔄 Charger le catalogue**. Le statut doit afficher `catalogue principal Djipie · main` et le nombre de sons accessibles, initialement 579.
4. Dans **MUSIQUES**, rechercher `guitare` ; dans **FX_EXPLOSIONS**, essayer `bang` ou `fw_loop`.
5. Le bouton d'écoute télécharge et vérifie uniquement le fichier demandé.

## Protection et limites
- Aucun fichier audio privé, archive de Djipie ni jeton GitHub n'est redistribué dans cette Release publique.
- Les sons et leurs licences restent gérés exclusivement dans Djipie.
- Aucune authentification à GitHub : catalogue indisponible, message explicite ; les réponses 401, 403 et 404 ne sont pas silencieusement remplacées par un vieux catalogue.
- Une application debug antérieure signée par une autre clé peut être impossible à mettre à jour sur Android : sauvegarder les données utiles avant toute désinstallation.
- Tests automatisés GitHub ≠ validation audio réelle sur Samsung ; connexion privée, lecture WAV/OGG, ergonomie et exports restent à tester sur appareil.
- Fichier `SHA256SUMS.txt` joint pour vérifier l'intégrité de l'APK.

**Évolution future :** les sons peuvent s'ajouter sans recompiler ni republier DashboardGit, tant que le format du catalogue et les autorisations privées restent compatibles.
